# Журнал изменений

Изменения по замечаниям итерации 2 (docs/feedback/iteration-2.md).
- FB-1: заочные ставки – FR-BID-10, вариант использования, API /absentee-bids (интерфейс IAbsenteeBids сервиса BidCapture), таблица absentee_bids в базе BidTracker.
- FB-2: подтверждение крупных ставок одноразовым кодом – FR-USR-09, диаграммы вариантов использования и последовательностей, API /auth/step-up, интерфейсы IStepUp и IStepUpVerify сервиса Identity.

- Сформирован единый комплект документации v1.1 (docs/HammerLive_Комплект_документации_v1.1.pdf) с руководствами пользователя и системного администратора.
