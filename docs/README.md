# Документация HammerLive

`HammerLive_Комплект_документации_v1.1.pdf` – единый комплект программной и эксплуатационной документации (сквозная нумерация страниц, общее оглавление):
1. Техническое задание (версия 1.1)
2. Спецификация архитектуры и API (версия 1.1)
3. Набор UML-диаграмм (версия 1.1)
4. Модель данных
5. Руководство пользователя
6. Руководство системного администратора

`feedback/` – замечания итерации 2, на основании которых выпущена версия 1.1.

`labs/` – отчёты лабораторных работ №1–5 в PDF, исходники в формате Word – в `labs/src/`.
