# Манифесты Kubernetes

Будут добавлены на этапе подготовки к опытной эксплуатации: Deployment и Service для каждого микросервиса, HorizontalPodAutoscaler для api-gateway, bid-capture и bid-streamer, StatefulSet для шардов bid-tracker (лоты распределяются по lotId) и кластера RabbitMQ, конфигурация Ingress.
